## API Endpoints

- POST `/user/register` — Register a user
- GET `/user` — Get all users
- GET `/user?role=admin` — Filter users by role
- GET `/user/:id` — Get user by ID
- PATCH `/user/:id` — Update a user
- DELETE `/user/:id` — Delete a user
